# 생강청 주문도우미

스마트스토어 주문을 놓치지 않게 도와주는 작은 서버와 웹앱입니다.

- **카톡 알림**: 새 주문(결제완료)이나 새 문의가 들어오면 카카오 알림톡을 보냅니다.
- **기사님 문자**: 발송할 주문의 받는 분 이름, 연락처, 주소, 품목을 한진 기사님께 보낼 문자로 정리합니다. 버튼을 누르면 내용이 채워진 문자앱이 열리고, 보내기만 누르면 됩니다. 기사님 번호는 설정에 저장하거나(안드로이드는 연락처에서 고르기 가능), 비워 두고 문자앱에서 고를 수 있습니다.
- **포장 확인**: 상자에 하나 넣을 때마다 탭해서 세고, 개수가 다 맞아야 "포장 완료"를 누를 수 있습니다.

```
[네이버 커머스API] ← 1분마다 확인 ← [서버 (고정 IP)]
                                      ├─▶ 카카오 알림톡
                                      └─▶ 웹앱 (폰 홈 화면에 추가해서 사용)
```

## 비밀 정보 규칙

이 저장소는 **공개** 저장소입니다. 아래 정보는 절대 커밋하지 않습니다.

| 정보 | 보관 위치 |
|---|---|
| 네이버 `client_id` / `client_secret`, 솔라피 키, 웹앱 비밀번호 | 서버의 `.env` 파일 (`.gitignore` 처리됨) |
| 고객 이름·주소·연락처 | 서버의 `data/state.json` (`.gitignore` 처리됨). 발송·취소되면 자동 삭제 |
| 기사님 번호, 보내는 분 정보 | 각자 폰의 브라우저 저장소 |

테스트와 예시 화면에는 가짜 데이터(`server/mock.js`, `web/demo-data.js`)만 씁니다.

```

├── products.json       상품 목록 (상품 추가는 여기에)

│   ├── naver.js        네이버 커머스API 연결
│   ├── notify.js       알림 (콘솔 / 카카오 알림톡)
│   ├── products.js     네이버 상품명 → 우리 상품 매칭
│   ├── store.js        상태 저장 (data/state.json)
│   └── mock.js         개발용 가짜 주문

```

## 상품 추가하기

`products.json`에 한 줄을 추가합니다. `match`는 네이버 상품명과 옵션에 **모두** 들어 있어야 하는 단어이고, `exclude`는 들어 있으면 안 되는 단어입니다.

```json
{ "id": "jujube-500", "name": "대추청 500g", "color": "#8b2c1a",
  "match": ["대추청", "500"], "exclude": ["스틱"] }
```

목록에 없는 상품이 주문되면 화면에 **미등록 상품**으로 표시됩니다.

## 개발용으로 실행하기 (가짜 데이터)

```bash
cd store-helper
npm install
cp .env.example .env        # APP_PASSWORD 를 바꾸세요
npm run dev                 # http://localhost:8080
npm test
```

## 실제 연결하기

### 1. 네이버 커머스API 앱 등록
1. [커머스API센터](https://apicenter.commerce.naver.com)에 판매자 계정으로 로그인합니다.
2. 애플리케이션을 등록하고 주문·문의 API 권한을 추가합니다.
3. **API 호출 IP**에 서버의 고정 IP를 등록합니다 (최대 3개).
4. 발급된 `client_id`, `client_secret`을 서버 `.env`에 넣고 `MOCK=0`으로 바꿉니다.

> 처음 실행하면 최근 3일 동안의 발송 전 주문을 가져옵니다.
> 네이버 API 응답 형식은 실제 계정으로 아직 검증하지 않았습니다. 첫 연결 때 서버 로그를 확인하세요.

### 2. 서버 준비 (고정 IP)
네이버 API는 등록한 IP에서만 호출할 수 있어서 고정 IP 서버가 필요합니다. 예: Oracle Cloud 무료 VM.
- Node.js 20 이상을 설치하고 이 폴더를 올린 뒤 `npm install && npm start`로 실행합니다.
- 폰에서 안전하게 접속하려면 HTTPS가 필요합니다 (예: Caddy + 무료 도메인).

### 3. 카카오 알림톡 (솔라피)
1. 사업자등록증으로 **카카오톡 채널**을 만들고 비즈니스 인증을 받습니다.
2. [솔라피](https://solapi.com)에 가입하고 채널을 연결합니다 (`SOLAPI_PF_ID`).
3. 아래 템플릿을 등록하고 카카오 검수를 받습니다 (1~3일).

   주문 알림 (`SOLAPI_TEMPLATE_ORDER`):
   ```
   [주문 알림]
   새 주문이 #{건수}건 들어왔어요.

   #{내용}

   확인하기: #{링크}
   ```
   문의 알림 (`SOLAPI_TEMPLATE_INQUIRY`):
   ```
   [문의 알림]
   답변을 기다리는 문의가 #{건수}건 있어요.

   #{내용}
   ```
4. `.env`에 `NOTIFY=alimtalk`와 솔라피 키, 받을 번호(`NOTIFY_TO`)를 넣습니다.

알림톡 발송이 실패하면 솔라피가 같은 내용을 문자로 대신 보냅니다. 알림에는 고객 이름을 `김*늘`처럼 가려서 보냅니다.

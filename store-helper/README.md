# 생강청 주문도우미

스마트스토어 주문을 놓치지 않게 도와주는 작은 서버와 웹앱입니다.

- **카톡 알림**: 새 주문(결제완료)이나 새 문의가 들어오면 카카오 알림톡을 보냅니다.
- **기사님 문자**: 발송할 주문의 받는 분 이름, 연락처, 주소, 품목을 한진 기사님께 보낼 문자로 정리합니다. 버튼을 누르면 내용이 채워진 문자앱이 열리고, 보내기만 누르면 됩니다. 기사님 번호는 설정에 저장하거나(안드로이드는 연락처에서 고르기 가능), 비워 두고 문자앱에서 고를 수 있습니다.
- **포장 확인**: 상자에 하나 넣을 때마다 탭해서 세고, 개수가 다 맞아야 "포장 완료"를 누를 수 있습니다.

```
[네이버 커머스API] ← 1분마다 확인 ← [서버 (고정 IP)]
                                      ├─▶ 카카오 알림톡
                                      └─▶ 웹앱 (폰 홈 화면에 추가해서 사용)
```

## 비밀 정보 규칙

이 저장소는 **공개** 저장소입니다. 아래 정보는 절대 커밋하지 않습니다.

| 정보 | 보관 위치 |
|---|---|
| 네이버 `client_id` / `client_secret`, 솔라피 키, 웹앱 비밀번호 | 서버의 `.env` 파일 (`.gitignore` 처리됨) |
| 로그인 토큰 서명용 비밀값 | 서버의 `data/secret` (처음 실행할 때 자동 생성, `.gitignore` 처리됨) |
| 고객 이름·주소·연락처, 배송메모, 문의 내용 | **서버 메모리에만** 최대 10분. 디스크에 저장하지 않고 필요할 때 네이버에서 다시 조회 |
| 주문번호, 상품, 수량, 포장 여부 | 서버의 `data/state.json` (`.gitignore` 처리됨, 서버 관리자만 읽기 가능) |
| 기사님 번호, 보내는 분 정보 | 각자 폰의 브라우저 저장소 |

테스트와 예시 화면에는 가짜 데이터(`server/mock.js`, `web/demo-data.js`)만 씁니다.

## 보안

| 위험 | 막는 방법 |
|---|---|
| 비밀번호 무작위 대입 | 같은 IP에서 15분 안에 5번 틀리면 15분 잠금. 여러 IP에서 1시간에 30번 틀리면 모든 로그인 15분 잠금 |
| 폰에 저장된 로그인 정보 유출 | 비밀번호는 폰에 저장하지 않음. 로그인하면 30일짜리 서명된 토큰을 **HttpOnly 쿠키**로 받음 (페이지 스크립트가 읽을 수 없음) |
| 폰 분실 | 다른 폰에서 설정 → **모든 기기 로그아웃**. 비밀번호를 바꿔도 모든 기기가 로그아웃됨 |
| 다른 사이트가 몰래 요청 보내기 | 쿠키 `SameSite=Strict` + 모든 변경 요청에 `X-App` 헤더 필수 |
| 통신 엿보기 | HTTPS 필수 (아래 Caddy 설정). 서버는 `127.0.0.1`에서만 듣고 Caddy를 거쳐서만 접속 |
| 서버 해킹 시 고객 정보 유출 | 고객 정보를 디스크에 저장하지 않음. 네이버 API 키는 등록한 서버 IP에서만 작동 |
| 화면에 악성 코드 넣기 | 모든 글자를 이스케이프하고, 보안 헤더(CSP, X-Frame-Options)로 외부 스크립트와 끼워넣기 차단 |
| 오류 메시지로 내부 정보 노출 | 서버 오류 내용은 로그에만 남기고 화면에는 짧은 안내만 표시 |

실제 운영 전 체크리스트:
- [ ] `APP_PASSWORD`는 12자 이상, 다른 곳에서 쓰지 않는 것 (짧으면 서버가 실행되지 않음)
- [ ] `APP_URL`이 `https://`로 시작 (아니면 경고)
- [ ] Caddy로 HTTPS 설정, 방화벽은 80·443만 열기
- [ ] 서버 접속은 SSH 키로만, 자동 보안 업데이트 켜기
- [ ] 어머니 폰과 내 폰에 화면 잠금

## 상품 추가하기

`products.json`에 한 줄을 추가합니다. `match`는 네이버 상품명과 옵션에 **모두** 들어 있어야 하는 단어이고, `exclude`는 들어 있으면 안 되는 단어입니다.

```json
{ "id": "jujube-500", "name": "대추청 500g", "color": "#8b2c1a",
  "match": ["대추청", "500"], "exclude": ["스틱"] }
```

목록에 없는 상품이 주문되면 화면에 **미등록 상품**으로 표시됩니다.

스토어마다 상품 이름이 다르면 그 스토어용 규칙을 따로 적을 수 있습니다.

```json
{ "id": "ginger-650", "name": "착즙 생강청 650g", "color": "#c98a1b",
  "match": ["생강청", "650"], "exclude": ["레몬", "스틱"],
  "channels": { "coupang": { "match": ["생강차", "650"], "exclude": ["레몬"] } } }
```

## 새 스토어 연결하기 (예: 쿠팡)

1. `server/channels/coupang.js`를 `naver.js`와 같은 모양으로 만듭니다. 필요한 함수와 공통 주문 형식은 `server/channels/index.js` 맨 위 설명에 있습니다.
   - `pending`: 어머니가 포장·발송해야 하는 주문이면 `true` (쿠팡이 직접 배송하는 로켓그로스 주문은 `false`)
2. `server/channels/index.js`의 `ALL_CHANNELS` 목록에 추가합니다.
3. `.env`에 그 스토어의 키를 넣고 `config.js`에서 읽게 합니다.
4. 상품 이름이 다르면 `products.json`에 `channels` 규칙을 추가합니다.

스토어마다 따로 확인하므로 한 스토어에 문제가 생겨도 다른 스토어 알림은 계속 옵니다. 문제가 생긴 스토어는 화면 위쪽에 빨간 글씨로 표시됩니다.
스토어가 2개 이상이면 주문과 문의마다 스토어 이름이 붙고, 알림에도 `[네이버]`, `[쿠팡]`처럼 표시됩니다.

## 개발용으로 실행하기 (가짜 데이터)

```bash
cd store-helper
npm install
cp .env.example .env        # APP_PASSWORD 를 바꾸세요
npm run dev                 # http://localhost:8080
npm test

# 아이폰 미리보기용 한 파일 HTML (예시 데이터)
python3 scripts/build-preview.py preview.html
```

## 실제 연결하기

### 1. 네이버 커머스API 앱 등록
1. [커머스API센터](https://apicenter.commerce.naver.com)에 판매자 계정으로 로그인합니다.
2. 애플리케이션을 등록하고 주문·문의 API 권한을 추가합니다.
3. **API 호출 IP**에 서버의 고정 IP를 등록합니다 (최대 3개).
4. 발급된 `client_id`, `client_secret`을 서버 `.env`에 넣고 `MOCK=0`으로 바꿉니다.

> 처음 실행하면 최근 3일 동안의 발송 전 주문을 가져옵니다.
> 네이버 API 응답 형식은 실제 계정으로 아직 검증하지 않았습니다. 첫 연결 때 서버 로그를 확인하세요.

### 2. 서버 준비 (고정 IP)
네이버 API는 등록한 IP에서만 호출할 수 있어서 고정 IP 서버가 필요합니다. 예: Oracle Cloud 무료 VM.
- Node.js 20 이상을 설치하고 이 폴더를 올린 뒤 `npm install && npm start`로 실행합니다.
- `.env`에 `HOST=127.0.0.1`, `TRUST_PROXY=1`, `APP_URL=https://내도메인`을 넣습니다.

### 3. HTTPS (Caddy)
1. 도메인을 준비합니다. 무료로는 DuckDNS(`이름.duckdns.org`)에서 서버 IP를 연결할 수 있습니다.
2. 서버에 Caddy를 설치합니다.
3. `deploy/Caddyfile.example`을 `/etc/caddy/Caddyfile`로 복사하고 도메인을 바꾼 뒤 Caddy를 다시 시작합니다.
4. 인증서는 Caddy가 자동으로 받고 갱신합니다. 방화벽은 80(인증서 발급용)과 443만 엽니다.

### 4. 카카오 알림톡 (솔라피)
1. 사업자등록증으로 **카카오톡 채널**을 만들고 비즈니스 인증을 받습니다.
2. [솔라피](https://solapi.com)에 가입하고 채널을 연결합니다 (`SOLAPI_PF_ID`).
3. 아래 템플릿을 등록하고 카카오 검수를 받습니다 (1~3일).

   주문 알림 (`SOLAPI_TEMPLATE_ORDER`):
   ```
   [주문 알림]
   새 주문이 #{건수}건 들어왔어요.

   #{내용}

   확인하기: #{링크}
   ```
   문의 알림 (`SOLAPI_TEMPLATE_INQUIRY`):
   ```
   [문의 알림]
   답변을 기다리는 문의가 #{건수}건 있어요.

   #{내용}
   ```
4. `.env`에 `NOTIFY=alimtalk`와 솔라피 키, 받을 번호(`NOTIFY_TO`)를 넣습니다.

알림톡 발송이 실패하면 솔라피가 같은 내용을 문자로 대신 보냅니다. 알림에는 고객 이름을 `김*늘`처럼 가려서 보냅니다.
